Export Open Graph image (1200×630)
  1. Open DevTools → Elements.
  2. Select #og-card (right-click the card → Inspect).
  3. In the Elements panel, right-click the #og-card node → Capture node screenshot.
  4. Save as og-image.jpg or og-image.png in the project root (Chrome captures at device pixel ratio — use 100% zoom for exact 1200×630, or keep 2× for a sharper asset).
